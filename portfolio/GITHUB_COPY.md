## Pinned repository summary

LedgerFlow demonstrates a complete operational workflow rather than a collection of disconnected screens. It accepts documents, prevents duplicate intake, extracts known fields, assigns confidence, requires human approval for uncertain data, synchronizes requirement status, logs reminders, and exports the collection register.
