# LedgerFlow 60-Second Demo Script

Target: one MP4, 55-60 seconds, 16:9, 1080p. Keep the pointer movement slow and do not show browser bookmarks, notifications, or personal accounts.

## 0-6 seconds - Opening

On screen: LedgerFlow dashboard.

Voiceover:

"LedgerFlow is a full-stack document operations platform for teams that collect recurring client files."

## 6-16 seconds - Collection control

On screen: Open Collections and briefly show overdue, missing, in-review, and received requirements.

Voiceover:

"Each requirement tracks the client, reporting period, due date, current state, and reminder history."

## 16-27 seconds - Intake and safeguards

On screen: Open the upload dialog, select a synthetic example document, and process it.

Voiceover:

"Uploads are validated, hashed for duplicate detection, classified, and matched to the expected reporting period."

## 27-39 seconds - Human review

On screen: Open the low-confidence bank statement review panel. Pause on extracted fields and warnings.

Voiceover:

"Confidence controls the workflow. Uncertain fields never complete a requirement without a human decision."

## 39-49 seconds - Audit and reminders

On screen: Show the Audit Trail, then briefly return to a requirement with reminder history.

Voiceover:

"Approvals, reminders, uploads, and requirement changes create a traceable audit record. Repeated reminder actions are suppressed for 24 hours."

## 49-60 seconds - Engineering close

On screen: Architecture image followed by the dashboard cover.

Voiceover:

"The application uses Vue 3, TypeScript, FastAPI, SQLAlchemy, automated API tests, and explicit boundaries for production storage, OCR, and authentication."

End card:

`LedgerFlow | Vue 3 + TypeScript + FastAPI + SQLAlchemy`

Small footer:

`Independent portfolio project - synthetic demo data`
