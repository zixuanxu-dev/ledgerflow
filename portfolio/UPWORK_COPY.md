# LedgerFlow Upwork Portfolio Copy

## Project title

LedgerFlow - Document Workflow SaaS

## Role

Full-Stack Developer and Product Engineer

## Project description

Designed and built an end-to-end document collection platform for recurring client workflows. The system combines a Vue 3 dashboard, FastAPI API, document classification, confidence-based human review, duplicate detection, reminders, audit logs, and CSV export. This is an independent portfolio project built with synthetic data; no client information is included.

## Short proposal reference

I recently built LedgerFlow, a full-stack document workflow application using Vue 3, TypeScript, FastAPI, and SQLAlchemy. It includes file intake, duplicate detection, confidence-based human review, reminders, audit logs, and CSV export. The architecture and review workflow are directly relevant to projects that need reliable operational automation rather than a simple CRUD interface.

LedgerFlow is a self-directed portfolio project, not paid client work. All companies, email addresses, documents, and amounts shown in the demo are synthetic.
